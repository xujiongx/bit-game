|------|------|
| 产品名称 | 差一点 |

---

## 1. 背景与目标

### 1.1 产品一句话

「差一点」是一款轻量、偏手感的点击节奏小游戏：圆环不断收缩，玩家在合适时机点击靠近圆心获得高分。

### 1.2 目标用户

- 碎片时间玩家（通勤、排队）
- 喜欢短局、可重复挑战的轻度竞技用户
- 愿意为本地成长（任务 / 皮肤 / 金币）回流的用户

### 1.3 产品目标

1. **核心爽感**：判断时机 → 点击 → 即时反馈（分数 / 连击 / 音效）
2. **短局可玩**：经典模式「一点即终」；限时模式「1 分钟冲分」
3. **本地成长**：金币、任务、成就、皮肤、排行，形成回访动机
4. **微信适配**：纯 Canvas、安全区 / 胶囊避让、触控反馈稳定

### 1.4 非目标（当前版本不做）

- 实时联网对战、云端排行榜
- 强制看广告复活（当前为金币复活）
- 复杂社交、公会、赛季战令

## 2. 核心玩法

### 2.1 基础规则

1. 屏幕随机位置出现目标圆环，半径随时间从大变小。
2. 玩家点击圆环有效范围内判定命中；越靠近圆心，得分越高。
3. 命中后进入短间隔，再生成下一目标；连击提升分数倍率与难度。
4. 特殊机制：
   - **首领回合**：经典模式下每 10 回合出现（限时模式关闭）
   - **狂热模式**：连击达到 10 / 20 / 30 / 40 时触发，限时内得分 ×2

### 2.2 命中档位（示意）

| 判定 | 条件（相对半径） | 基础分（非首领） |
|------|------------------|------------------|
| 完美 | 精度 > 0.88 | 30 |
| 优秀 | 精度 > 0.58 | 18 |
| 命中 | 其余有效命中 | 10 |
| 首领 | Boss 目标 | 80 + 连击加成 |

最终得分还会乘以连击系数；狂热期间再 ×2。

## 3. 游戏模式

### 3.1 经典模式

- 入口：首页「开始挑战」
- 规则：点空 / 圆环超时 → **本局结束**
- 结算：可消耗金币复活（见经济系统）
- 记录：写入「经典」本地排行

### 3.2 限时模式

- 入口：首页「限时模式 · 1 分钟」
- 规则：
  - 倒计时 **60 秒**（暂停时冻结）
  - **未命中 / 圆环消失不计分**，连击清零，继续下一目标
  - 时间结束自动结算
- 复活：不可用
- 记录：写入「限时」本地排行与限时最高分

### 3.3 每日挑战

- 入口：首页「每日挑战」→「开始今日挑战」
- 规则：在经典逻辑上提高难度（目标更小 / 更快）
- 记录：今日最高分；同时计入经典排行与任务进度

## 4. 界面与信息架构

```
首页
├── 开始挑战（经典）
├── 限时模式 · 1 分钟
├── 每日挑战
├── 任务（每日 / 成就）
├── 排行榜（经典 / 限时）
├── 皮肤
├── 今日奖励
└── 声音开关

对局 HUD：最高或剩余时间 / 得分 / 连击 / 进度条 / 暂停
结算卡：分数、纪录对比、复活（条件满足时）、重开、回首页
暂停卡：继续、退出本局
```

### 4.1 交互规范

- 所有操作按钮：按下缩放 + 变色 + 轻震动；**抬起且仍在按钮上才触发**
- 对局点击圆环：按下即判定（保证手感）
- 任务列表过长：支持上滑滚动

## 5. 经济与成长

### 5.1 金币

| 来源 | 说明 | 数量 |
|------|------|------|
| 今日奖励 | 每日手动领取一次 | +20 |
| 每日任务 | 完成后手动领取 | 8～18 / 个 |
| 成就任务 | 完成后手动领取 | 30～130 / 个 |

| 消耗 | 说明 | 数量 |
|------|------|------|
| 立即复活 | 经典 / 每日挑战结算 | −5 / 次，每局最多 3 次 |

### 5.2 复活规则

- 按钮文案：`立即复活 · 5 金币（剩 N 次）`
- 金币不足：提示，不扣费
- 本局已满 3 次：隐藏复活按钮
- 限时模式：无复活

### 5.3 皮肤

- 按经典最高分解锁（0 / 300 / 800 / 1500 / 2500 / 4000）
- 影响：背景色 + 圆环主题色
- 仅本地切换，无付费皮肤（当前）

## 6. 任务系统

### 6.1 每日任务（每天刷新）

示例：

- 完成任意 1 局（8）
- 单局达到 100 分（12）
- 单局达到 ×5 连击（12）
- 限时模式玩 1 局（15）
- 今日挑战达到 150 分（18）

进度按「当日统计」计算；奖励需手动领取，防重复领。

### 6.2 成就任务（永久，16 个，高难度）

| 类型 | 门槛示例 | 奖励区间 |
|------|----------|----------|
| 经典最高分 | 800 / 1500 / 3000 / 5000 | 30～120 |
| 最高连击 | ×12 / ×20 / ×35 / ×50 | 30～130 |
| 限时最高分 | 600 / 1200 / 2000 | 40～110 |
| 累计局数 | 20 / 60 / 150 | 30～100 |
| 皮肤解锁 | 3 个 / 全部 6 个 | 45～90 |

---

## 7. 排行榜（本地）

- 分栏：**经典模式** / **限时模式**
- 仅本地记录，各保留最多 20 条，按分数降序
- 每条展示：名次、分数、连击 / 回合、游玩时间（今天 / 昨天 / 日期）
- 经典额外可展示本局用时；限时标注「1 分钟」
- 成绩入库时机：限时结束立即写入；经典若仍可复活则挂起，最终结算或离开结算页时写入

## 8. 技术约束（实现侧）

| 项 | 要求 |
|----|------|
| 渲染 | 微信小游戏主 Canvas，无 DOM |
| 适配 | `windowWidth/Height` + 安全区 + 胶囊按钮避让 |
| 时间 | 统一墙钟推进，避免 rAF / performance 不一致 |
| 存档 | `wx.setStorageSync`，键前缀 `v10_` |
| 音效 | WebAudio（`wx.createWebAudioContext`），失败静默 |
| 图标 | SVG 资源 + Canvas 路径复刻（`js/icons.js`） |

### 8.1 主要模块

```
game.js                 入口
js/main.js              状态机 / UI / 玩法
js/render.js            Canvas 与触控坐标
js/storage.js           本地 KV / JSON
js/audio.js             音效
js/icons.js             矢量图标绘制
js/tasks.js             每日 / 成就任务
images/icons/*.svg      图标源文件
docs/PRD.md             本文档
```

## 9. 成功指标（建议）

| 指标 | 说明 | 初期目标（建议） |
|------|------|------------------|
| 次日留存 | 打开后次日再进 | ≥ 25% |
| 人均局数 / 日 | 含经典 + 限时 | ≥ 4 |
| 任务领取率 | 有完成任务的用户中领取占比 | ≥ 60% |
| 限时模式占比 | 限时开局 / 总开局 | 15%～35% |
| 崩溃率 | 真机异常退出 | < 0.5% |

（当前为单机本地产品，指标需在接入分析后统计。）

## 11. 风险与依赖

| 风险 | 影响 | 缓解 |
|------|------|------|
| 真机触控坐标差异 | 点不准、误判 miss | 统一逻辑像素；限时模式容错 |
| 成就门槛过高 | 领取率低、挫败 | 保留低档每日任务；成就做长线 |
| 仅本地存档 | 换机丢失 | 后续可接云存储 / 用户数据 |
| 审核对虚拟货币 | 上架合规 | 金币仅本地、无人民币直购（当前） |
